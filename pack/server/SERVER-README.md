# Inventors dedicated server

This archive contains the server-compatible Inventors mods, configuration, quests, and KubeJS content. Client-only mods and configuration are intentionally omitted.

Requirements:

- Java 21
- At least 6 GB RAM recommended

Windows: run `start-server.bat`.

Linux/macOS: run `chmod +x start-server.sh`, then `./start-server.sh`.

The first launch installs NeoForge and creates `eula.txt`. Read Mojang's EULA, change `eula=false` to `eula=true` only if you agree, then launch again. The pack never pre-accepts the EULA.

Worlds, logs, backups, and player data are not included in release archives.
