# Branding and media assets

This directory holds the visual assets used by GitHub and the CurseForge project page so both stay consistent:

- `banner.png` — repository banner / CurseForge description header (wide format, ~1920×480)
- `logo.png` — square pack logo
- `screenshot-*.png` — representative gameplay screenshots (base, quern/animal power, Create automation)

Drop files here with those names and reference them from `README.md` and `docs/CURSEFORGE.md`.
